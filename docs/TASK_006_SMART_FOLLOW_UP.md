### 3. دورة حياة التذكيرات والتأجيل (`Reminders & Snooze`)
- **معرّف حتمي (`Deterministic ID`)**:
  - يُبنى بالصيغة `rem_{sourceType}_{sourceId}_{reason}` لضمان عدم تكرار التذكير لنفس الكيان والسبب عند إعادة التقييم أو تحديث الجلسة.
- **الحالات الأربع المعتمدة**:
  1. `active` (**نشط**): مؤهل للظهور حالياً ضمن نوافذ التفضيلات.
  2. `snoozed` (**مؤجل**): مؤجل مؤقتاً حتى `snoozedUntil`؛ يختفي من الشارة النشطة حتى يحين الموعد ثم يعود تلقائياً إلى `active`.
  3. `resolved` (**تمت معالجته**): أخفاه المستخدم يدوياً دون إكمال المهمة أو إلغاء الاجتماع الأصل.
  4. `invalidated` (**لم يعد صالحًا**): عند إكمال المهمة أو حذفها، أو إلغاء/إتمام الاجتماع، أو تغيّر `sourceFingerprint` (تعديل تاريخ/حالة المصدر)، تُبطل صلاحية الحالة المؤجلة أو المخفية تلقائياً مع سبب عربي واضح.
- **خيارات التأجيل («ذكّرني لاحقًا»)**:
  - بعد ساعة (`1h`)، غدًا 9:00 ص (`tomorrow`)، بعد 3 أيام (`3d`)، الأسبوع القادم (`next_week`)، أو تحديد موعد مخصص (`custom`) مع رفض التواريخ الماضية.
  - **حماية سلامة البيانات**: التأجيل يكتب فقط في `/users/{uid}/reminders/{reminderId}` ولا يعدّل `task.dueDate` ولا يُنشئ مهاماً مكررة.

### 4. التفضيلات والتخزين المحلي والمناطق الزمنية
- **تفضيلات المتابعة (`/users/{uid}/preferences/follow_up`)**:
  - `remindersEnabled`، `showOverdueTasks`، `showUpcomingMeetings`، `meetingLeadMinutes` (`15 | 30 | 60 | 120 | 1440`)، `upcomingTaskWindowDays` (`0 | 2 | 3 | 7`)، `showStaleClients`، `staleClientDays`.
  - تعطيل التذكيرات يخفي التنبيهات فقط دون حذف أو تعطيل أي مهمة أو اجتماع أو عميل.
- **سلامة المناطق الزمنية (`Timezone Safety`)**:
  - جميع تواريخ المهام بصيغة `YYYY-MM-DD` تُفسَّر كتاريخ تقويمي حرفي عبر `parseDateOnlyString` و`calendarDaysDiff` في `followUpEngine.ts` و`logic.ts` و`client360.ts`، ما يمنع انزياح اليوم للخلف في المناطق الزمنية السالبة (مثل `America/Los_Angeles`) أو عند حدود منتصف الليل (`23:59` ← `00:00`) والسنوات الكبيسة.
  - ساعة حية (`referenceDate`) تُحدّث كل 60 ثانية وعند عودة تبويب المتصفح (`visibilitychange`) وعودة الاتصال (`online`).
- **العمل دون اتصال والمزامنة**:
  - يلتزم بالتكوين الافتراضي للذاكرة فقط (`Memory-Only Default`) والتخزين الدائم الاختياري (`IndexedDB Opt-In`) دون تخزين أي بيانات عملاء أو تذكيرات في `localStorage`.
  - تُراقب مجموعتا `reminders` و`preferences` عبر `OperationCoordinator` و`collectionSync` لتعكس حالة المزامنة (`local` / `pending` / `synced` / `failed`) بأمان ودون فقدان المسودات عند رفض الخادم.
